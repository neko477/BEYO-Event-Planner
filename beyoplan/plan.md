# BEYO Event Planner — 実装計画

## 目的と範囲
BEYOOOOONDS 7thシングル『笑止千万／勝利のセンタク』発売記念イベントについて、forTUNE musicイベントとWithLIVEオンラインお話し会の参加予定・CD購入枚数・費用を個人で整理するブラウザ完結型の計算ツールを作る。購入予定数は公式上限を超えないよう制御し、イベント別と全体の費用・CD枚数を即時表示する。価格・上限・送料・手数料・予定は利用者が後から編集でき、端末のブラウザに保存される。

### 確認済みの初期データ
- forTUNE music：公式告知の6カテゴリ、1回のお申し込みにおける購入上限、商品構成、定価、5会場日の部別時刻を初期データにする。
  - 3/4ショットチェキ、2ショットチェキ、個別サイン、個別お絵描きは4枚セット・6,780円（上限は各75/165/165/165セット）。
  - グループお話し会、個別お話し会は1枚・1,300円（上限は各150/900セット）。
  - お話し会の送料700円、前払いの1配送あたり手数料187円を編集可能な費用項目として初期登録する。
- WithLIVE：公式一覧に掲載された10月27日・29日・30日の開始予定時刻と参加メンバーを初期データにする。販売詳細は2026年10月8日19時公開予定のため、価格・上限は「要確認」と明示しつつ、仮の通常盤1枚・1,300円と任意の上限を設定画面で修正できるようにする。未確認のまま確定値のようには扱わない。

## 実装方針
- Vite + React + TypeScriptの静的SPAとして実装する。ログイン、サーバー、外部API、データベースは使わない。
- `src/data.ts`に公式初期データとイベント定義を持たせ、`src/App.tsx`が予定行、費用行、商品設定を状態管理する。
- 状態は`localStorage`に保存・復元する。ブラウザ内だけに保存され、入力値を外部へ送信しない。
- 予定は「イベントを追加」から作成する。種別を選ぶと、対応する日付・部・時間・価格・上限・CD枚数が初期入力され、数量は0〜上限に限定する。上限まで使用したときのメーターと、上限超過の警告を表示する。
- 合計額は選択行の `数量 × 単価` と有効な追加費用の合計、総CD枚数は `数量 × 1セット当たりCD枚数` から算出する。サービス別小計も表示する。
- 設定ドロワーで商品単価、上限、CD枚数、送料・手数料を編集する。設定値の変更は既存予定の新規作成時に反映する。費用項目は有効/無効・金額・回数を変更できる。
- 「一覧をコピー」と「データをリセット」を提供する。コピー内容はテキストのスケジュールと費用内訳で、リセット前には確認ダイアログを表示する。

## デザイン方針
- **Design Movement:** ライブの整理券とツアー台帳を組み合わせた、明るく実用的な「Ticket Ledger」ダッシュボード。
- **Core Principles:** 1) 合計を常に視界の中心に置く、2) 日程と費用を一行で読める、3) 上限は数字と色で二重に伝える、4) 個人用ツールとして余計な装飾を省く。
- **Color Philosophy:** 背景は紙のような温かいクリーム、情報階層には濃紺、重要な合計には蛍光ライム、予定種別にはラベンダーとコーラルを使う。購入計画を明るく把握できる配色にする。
- **Layout Paradigm:** 上部を「今の総額」バンド、左を時系列の予定台帳、右を固定の集計・費用レールとする非対称な2カラム構成。画面が狭い場合は集計を先頭へ移す。
- **Signature Elements:** ジグザグのチケット端、上限の進捗リング、イベント種別の角丸スタンプ。
- **Interaction Philosophy:** 入力変更は即時計算・即保存。追加、編集、削除は局所的な操作にし、数値制限や未確認情報は控えめだが明確に提示する。
- **Animation:** 追加・削除時の短いフェード/スライド、合計変更時の控えめなハイライトのみ。操作を待たせるアニメーションは使わない。
- **Typography System:** 日本語本文はNoto Sans JP系のシステムフォント、数値と見出しはManrope系の太めのサンセリフを優先する。金額には等幅に近い数字機能を適用する。
- **Brand Essence:** 「推し活の予定と予算を、ひと目で迷わず決める個人用チケット台帳。」— 正確、軽快、親しみやすい。
- **Brand Voice:** 短く実務的に案内する。例：「予定を足して、合計を見よう」「公式情報は更新時に見直してください」。
- **Wordmark & Logo:** `BEYO / PLAN` をチケットのミシン目を挟む2段のワードマークにし、末尾のスラッシュを日程の区切り記号に見立てる。
- **Signature Brand Color:** `Electric Lime #C8FF2E`。

## プロジェクト構成
- `src/data.ts`：公式情報に基づくイベント種別・日程・デフォルト費用の初期データ。
- `src/types.ts`：予定、商品設定、費用項目の型定義。
- `src/App.tsx`：状態、計算、保存、画面コンポーネントを統合するアプリ本体。
- `src/main.tsx`：Reactエントリーポイント。
- `src/styles.css`：レスポンシブなTicket Ledgerデザイン。
- `public/manus-routes.json`：ルート宣言。
- `index.html`：メタデータとアプリマウントポイント。
